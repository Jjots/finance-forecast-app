# ЛР №4: Макроархитектура и развертывание (Катя — web_app / mobile_app)

## Цель
Спроектировать системный ландшафт (L0), динамическую диаграмму получения прогноза и схему локального развертывания для клиентских приложений.

## L0: Система и связи
На схеме `landscape_kate.puml` показана **вся система** `finance_system` как единый черный ящик внутри корпоративной границы. 
- Акторы: Аналитик, Инвестор, Риск-менеджер, Администратор.
- Внешние системы: РСБУ, ЦБ РФ, MOEX, а также проектируемые корпоративные IAM и BI.

## Dynamic: Пошаговый сценарий
На схеме `dynamic_kate_forecast.puml` показан основной путь получения прогноза аналитиком, когда локальный кэш устарел. 
1. Выбор компании → 2. Контроллер → 3. Сервис → 4. Проверка кэша (устарел) → 5. Запрос в API → 6. HTTPS к Backend → 7. Backend к ML → 8. Ответ обратно → 9. Кэширование → 10. Отрисовка.

**Альтернативы:**
- **A (кэш свежий):** шаги 6–8 пропускаются, данные берутся из `cache_repository`.
- **B (сервер недоступен):** показываются последние сохраненные данные из кэша с пометкой «устарело».

## Deployment: Узлы и безопасность
На схеме `deployment_kate.puml` показано физическое размещение.
- Пользовательские устройства (браузер и смартфон).
- Edge VM с Nginx (публичный вход).
- Application VM с Backend (приватная сеть).

## Что проектируется, а что уже описано
- **Проектируется:** IAM (OpenID Connect), BI, локальное развертывание на VM с Nginx.
- **Описано в L1-L3:** Backend, ML, БД, внутренние компоненты клиентов.
