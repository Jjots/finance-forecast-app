# Лабораторная работа №4 — Макроархитектура и развертывание

## Проект
Finance Forecast System — информационная система для анализа и прогнозирования финансовых показателей российских компаний.

## Общие архитектурные диаграммы

- `landscape.puml` — системный ландшафт L0.
- `dynamic_process.puml` — сценарий получения финансового прогноза.
- `dynamic_retraining.puml` — сценарий автоматического переобучения ML-модели.
- `deployment.puml` — общая диаграмма развертывания.
- `ARCHITECTURE_DECISIONS.md` — согласованные архитектурные решения.

## Работы участников

- `kate/` — Web App и Mobile App.
- `diana/` — Backend и ML Service.
- `igor/` — PostgreSQL и TimescaleDB.
- `danya/` — Scheduler и RabbitMQ.

Каждый участник подготовил локальные диаграммы системного ландшафта, динамических процессов и развертывания.

## Основные архитектурные решения

- Клиентские приложения взаимодействуют с Backend через Nginx.
- ML Service размещается на отдельном сервере.
- Scheduler автоматизирует загрузку данных и переобучение моделей.
- RabbitMQ обеспечивает передачу фоновых задач.
- PostgreSQL и TimescaleDB размещаются в приватной сети.
- Для баз данных предусмотрены реплики на отдельном сервере.

Взаимодействия используют HTTPS, REST, SQL/TCP и AMQPS. Серверная инфраструктура и корпоративные интеграции описаны как проектируемые.
