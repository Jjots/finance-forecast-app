
# Export Service — L4

Учебный прототип компонента `export_service` информационной системы Finance Forecast System.

## Назначение

Компонент предназначен для создания финансовых отчётов в форматах PDF и Excel.

В реализации используется паттерн проектирования Strategy, который позволяет переключать формат экспорта без изменения основной логики.

Технологии: TypeScript, jsPDF, SheetJS.

## Установка

Из папки `src/l4-code/kate-export` выполнить:

    npm install

## Запуск браузерной демонстрации

Собрать JavaScript для браузера:

    npm run build:demo

После сборки открыть файл `demo.html` через локальный HTTP-сервер, например Live Server в VS Code.

На странице будут две кнопки:
- «Скачать PDF»
- «Скачать Excel»

При нажатии создаётся и скачивается соответствующий файл с тестовыми финансовыми данными.

## Тестирование

Запустить автоматические тесты:

    npm test

## Структура классов

- `FinancialReport` — модель финансовых данных.
- `ExportStrategy` — общий интерфейс стратегий.
- `PdfExportStrategy` — генерация PDF через jsPDF.
- `ExcelExportStrategy` — генерация Excel через SheetJS.
- `ExportContext` — выбор и переключение стратегии.

## Ограничения

В прототипе используются тестовые данные компании. Получение финансовых показателей из Backend пока не реализовано.

Компонент предназначен для интеграции в браузерное приложение React + TypeScript.
