# Приложение для анализа и прогнозирования финансовых показателей российских компаний

Курсовой проект по дисциплине «Информационные системы и технологии».

## Команда

| Роль                          | Имя   | Зона ответственности                 |
| Тимлид + Backend + ML + CI/CD | Алиса | Архитектура, api_backend, ml_service |
| Бизнес-аналитик + UI/UX       | Катя  | SWOT, SMART, Use-Case, UI            |
| Системный аналитик + Data     | Игорь | FURPS+, ER, схема dwh                |
| Backend-разработчик           | Диана | api_backend, интеграция с ML         |
| DevOps + QA                   | Даня  | queue, dwh, scheduler, CI/CD         |

## Стек

- Backend: Python + FastAPI
- ML: XGBoost + ARIMA
- БД: PostgreSQL + TimescaleDB
- Брокер: RabbitMQ
- Планировщик: Airflow / Celery
- Диаграммы: PlantUML + C4-PlantUML
