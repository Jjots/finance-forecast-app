## Контейнеры

| ID          | Контейнер                 | Технология                    | Ответственный |

## Правила

1. ID пишутся латиницей, snake_case
2. Все связи в PlantUML используют только эти ID.
3. Только макрос `Rel(...)` — без `Rel_D/R/L/U`.
4. Без `skinparam` в файлах разработчиков.
